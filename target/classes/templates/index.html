Formulir Permohonan Cuti Mahasiswa

Isi form di bawah ini. Saat disubmit, sistem akan secara otomatis membuat instance alur kerja baru pada Camunda BPMN Engine dan memicu Service Task Validasi serta User Task Dosen Pembimbing.

Gunakan format NIM resmi Program Studi Teknik Informatika.
Panduan Simulasi Workflow:
  1. Kirimkan formulir pengajuan di atas.
  2. Buka menu Inbox Persetujuan untuk bertindak sebagai Dosen Pembimbing (Approve/Reject).
  3. Jika disetujui Dosen, tugas akan berpindah ke antrean Ketua Program Studi.
  4. Pantau seluruh pergerakan status pada halaman Monitoring Status.
